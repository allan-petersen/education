Yes, Java 8 (including jdk8u302-b08) commonly fails to read .p12 (PKCS#12) files generated by newer Java versions (such as Java 11, 17, or 21).
While 8u302 added support for newer PKCS#12 properties, it still struggles with the stronger default cryptographic algorithms introduced in modern JDKs (specifically Java 16+).

Why It Happens

• Stronger Default Encryption. Newer Java versions encrypt PKCS#12 keystores using PBEWithHmacSHA256AndAES_256 and HmacPBESHA256 by default.
• Legacy Expectations in Java 8. Java 8 defaults to older algorithms (like 3DES, RC2, and HmacPBESHA1). When it encounters modern PBES2/AES-256 parameters or SHA-256 MAC algorithms without explicit backport support, it typically throws an IOException (such as Invalid keystore format, keystore password was incorrect, or parseAlgParameters failed).
